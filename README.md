# Steel Wire

A simple ContentLib mod, that adds steel wire as alternate recipe, so more of
your production chains can be automated via steel.

Steel Wire can be unlocked via hard drive after unlocking Basic Steel Production
in the hub.

- 15 Steel Ingots -> 60 Wire
- Cycle Time: 60s
